Structured-field pipeline update
================================

This package contains only the updated pipeline/ directory.

On your cleanup branch:
1. Keep a clean git working tree.
2. Replace your existing pipeline/ directory with this pipeline/ directory.
3. Put Mini_Dataset.csv and per_protein_variant_stats_v2.csv at repo root as usual.
4. Run: python -m pipeline.build
5. Check: git diff --stat
6. Commit the pipeline changes only after the build/validation succeeds.

New behavior:
- New IDR_<NAME> parallel-list columns auto-map to idr_segments[].<name>.
- New Domains_<NAME> dictionary columns auto-map to domain_types[].<name>.
- Alignment/key mismatches fail validation.
- Irregular condensate fields have one central registry in pipeline/field_families.py.

See pipeline/FIELD_EXTENSIONS.md.
